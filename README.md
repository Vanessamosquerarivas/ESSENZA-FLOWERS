 ESSENZA FLOWERS

Diseño, elegancia y belleza floral en un solo lugar.

📖 Descripción del proyecto

ESSENZA FLOWERS es un proyecto de desarrollo web enfocado en una floristería. Su propósito es presentar un catálogo de arreglos florales mediante una interfaz visual elegante, organizada y atractiva.

La página permite explorar diferentes opciones florales, conocer las ocasiones especiales y encontrar información de contacto.

El diseño utiliza una identidad visual delicada, con tonos rosados, blancos y beige, que transmiten elegancia y armonía.

🎯 Objetivo del proyecto

Desarrollar una página web para una floristería que permita presentar sus productos y servicios de manera organizada, ofreciendo una experiencia visual agradable y una navegación sencilla.

✨ Características principales

Página de inicio con presentación de la floristería.

Catálogo de flores compuesto por 13 tarjetas.

Sección de ocasiones especiales.

Sección de contacto.

Diseño visual con una identidad gráfica floral.

Organización del contenido mediante secciones.

Estilos personalizados utilizando CSS y Tailwind CSS.

🎨 Identidad visual

La identidad visual de ESSENZA FLOWERS está inspirada en la delicadeza y elegancia de las flores.

Paleta de colores:

Rosa profundo.

Rosa pastel.

Blanco.

Beige.

Estos colores permiten mantener una apariencia armoniosa y coherente con la temática de la floristería.

🚀 Instalación y ejecución

Descargar o clonar el repositorio.

Abrir la carpeta del proyecto en Visual Studio Code.

Instalar las dependencias definidas en package.json ejecutando:

npm install

Abrir el archivo index.html en el navegador para visualizar el proyecto.
